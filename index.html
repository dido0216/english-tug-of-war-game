👩‍🏫 For Teachers — Publish on Google Sites & Edit Questions

Embed in Google Sites: 1) Host this single index.html file (e.g. GitHub Pages, Netlify Drop, or your school web space). 2) In Google Sites choose Insert → Embed → URL, paste the hosted address, and set it to full width. 3) Publish — students can play on computers, tablets, or the classroom projector. No account or server is needed, and the game works offline after it loads.

Edit questions: Open index.html in a text editor, find the QUESTION_BANK array in the script, and copy any question block to add your own: cat, diff, q, zh, options (4), answer (0–3), explain.
